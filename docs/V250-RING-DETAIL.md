# v250 — 让密度波和 E 环从「看不见」变成「看得见」

上一版我说这两件事做了也没意义：密度波是亚像素、E 环在任何曝光下都低于背景。
这一版两个前提都改了，所以它们现在是真能看的。

## 0. 前提一：环剖面 LUT 从 2048 格提到 65536 格

原来 2048 格 = 59.6 km/格。近景机位下环面 0.5 km/px，一格就是 120 px 的色块，
环看起来是一条条平涂的带子。现在 **65536 格 ≈ 1.86 km/格**，和实测剖面的 1 km 采样对得上。

一维纹理同样受 `MAX_TEXTURE_SIZE` 限制（本机 8192），所以打成 **4096×16 的 2D 纹理**，
采样时把一维索引折成 (x, y)：

```glsl
vec2 ringLutUV(float t) {
  float idx = clamp(t, 0.0, 0.99999) * 65535.0;
  return vec2((mod(idx, 4096.0) + 0.5) / 4096.0, (floor(idx / 4096.0) + 0.5) / 16.0);
}
```

## 1. 前提二：环系近景机位

没有这个机位，加什么细节都是亚像素。相机放进环平面内、半径 1.6R 处、抬高约 5000 km，
朝内侧下方 42° 看：近处环物质约 2500 km 远 ≈ **0.5 km/px**，
一台 1080p 画面横跨约 500 km 的环面。

入口：停在土星上时左侧出现「◎ 环系近景」（`__SE.go('ring')`）。

## 2. 密度波

**共振半径是算出来的，不是摆出来的**：

```
r_L = a_sat · ((m−1)/m)^(2/3)
```

Mimas（a=185,539 km）代入 m=2 得 **116,880 km**，与文献里卡西尼缝外缘约 117,500 km
相差 0.5%——这个公式在这里是可信的。表里放了 Mimas / Janus / Epimetheus / Pandora /
Prometheus / Atlas / Pan 七颗卫星、m=2..4，筛出落在环内的 8 条。

shader 里每条波是 m 臂螺旋，相位 `m·φ + k(r)`，波长 λ 随远离共振点线性变长
（WKB 趋势），振幅 `exp(−3.2d)(1−d)` 衰减，最终乘到光深上：

```glsl
tau = max(0.0, tau * (1.0 + wave));
```

**关键的一条**：像素足迹比波长大时按 `smoothstep(1.6, 4.0, λ/px)` 淡出。
这就是为什么必须配套近景机位——远景下它们自动消失，不会变成摩尔纹。

验证：同机位开关 `uWaveN` 做差（`v250-density-wave-diff6x.png`，差异放大 6 倍），
差异呈从共振点发散的细条纹，而不是噪点或整片色差。

> 诚实边界：波长是按 WKB **趋势**标到观测量级的，不是逐条实测；
> 振幅也是量级取值。共振**位置**是算的，波形是近似的。

## 3. E 环

E 环是 3–5R 的**厚环面**（峰值在土卫二轨道 3.95R），法向光深 ~1e-5 量级。
它不是薄盘，所以做成体积：包围球里沿视线走 64 步，密度取

```
ρ ∝ exp(−((r−r₀)/w)²) · exp(−(z/h)²)
```

再按 `τ = ∫ρ ds`、`ρ₀ = τ_normal/(h√π)` 归一，最后 `1−exp(−τ)` 转成亮度。

**踩到的坑**：射线-球求交的根写成 `t = b ± √(b²−c)`，正确是 `t = −b ± √(b²−c)`。
符号错一位的结果是 `t1 ≤ t0`，全场 discard——片元着色器不报错，画面就是「什么都没有」。
定位办法是把 discard 分支临时改成输出红/蓝，一眼看出走的是哪条路。

**它有多暗（实测，不是形容）**：τ=5e-4 时，正常曝光下 E 环的辐射约 1e-4 量级，
换算成 0–255 只有 2/255。所以：

- 默认 `uGain = 1` → 看不见（这也解释了为什么它 1980 年才被发现）；
- 环系近景自动把显示增益设到 **40**（`?ering=40` / `__SE.eRingGain(40)`）→
  出现一圈淡蓝灰色的宽光环，边缘能看出环面厚度（`v250-ering.png`）；
- 另有 `__SE.longExposure(k)` 把整体曝光乘 k——那是真实长曝光的路子，
  土星会跟着过曝。

> 诚实边界：这个 40 是**显示增益**，不是物理亮度。物理亮度在任何单次曝光里都低于天光背景，
> 要同时看到土星和 E 环，现实中也只能靠长曝光/叠加。
