# v217 宇宙层交接 GPU 验证

## 本轮修复

- 真实目录点云 → 全天程序宇宙网不再以 `R > 6e24` 硬切换；使用现有 `sdssK` 形成 `procWebK` 交叉淡化，并把实际 gain 暴露到 `cosmicVisualInfo().proceduralWebGain`。
- 修复结构/星系标签判断：photoLayer 对象存在但不可见时不再被当作可见几何，避免目录→宇宙网/CMB时悬浮标签。
- CMB非连续旅程淡入窗口从 `26.0→26.50` 前移到 `25.60→26.35`，内部层硬隐藏从 `26.10` 延后到 `26.35`，为远景主体保留重叠过渡。

这组支持“清理内部层时CMB已经接管、没有黑帧/白色饱和团”的数值判断，不支持完整审美验收或跨分辨率像素数量直接比较。早期稀疏帧也不能全部归因于程序网开关：目录覆盖、视角、动态分辨率都会影响非黑像素数。

回归新增执行实际源代码提取表达式的数值测试：有/无真实目录、有/无FIL四种组合的0.01 decade单调有界交接；隐藏/显示照片层标签判断；CMB在旧阈值>.7、在新清理阈值=1。
