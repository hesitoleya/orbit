# v242 — 收尾那三件「尚未解决」的事

v241 结尾列了三条没解决的：全球图只是反照率拼图（金星/海王星只有 2k 源）、
土星环是程序化几何、月球没有真实高程。这一版逐条处理，能解决的解决，
解决不了的写清楚为什么。

---

## 1. 土星环：从「噪声带」换成真实径向剖面 + 几何光学

### 之前是什么

```js
let a = vn(...)*0.6 + vn(...)*0.4;                 // 几条噪声
a *= 1.0 - 0.88*smoothstep(0.60,0.635,r)*(...);    // 卡西尼缝，位置是手调的
float lit = 0.16 + 0.84*abs(dot(uRingN, uSunDirW)); // 常数亮度
```

环区边界靠 `smoothstep` 凑，缝在哪儿全凭眼睛，亮度是一条常数线，
环和球互不投影。而且环的外缘写的 2.52R —— 真实土星主环只到 2.269R（A 环），
2.52R 已经跑到主环外面去了。

### 现在是什么

**一条真实径向剖面**（`satRingLut`，2048 采样，float RGBA 1D 纹理）：

| 环区 | 半径 (km) | 半径 (R) | τ 量级 |
|---|---|---|---|
| D 环 | 66900–74510 | 1.110–1.236 | 0.01 |
| C 环 | 74658–92000 | 1.238–1.526 | 0.08–0.28，含 Maxwell 缝（87491） |
| B 环 | 92000–117580 | 1.526–1.951 | 0.55–4.2（内薄外厚） |
| 卡西尼缝 | 117580–122170 | 1.951–2.027 | 0.07–0.27，含 Huygens 内环 |
| A 环 | 122170–136775 | 2.027–2.269 | 0.5–0.8，含 Encke（133589）与 Keeler（136505） |
| 洛希缝 | 136775–139380 | — | 0.005 |
| F 环 | 140180–140560 | 2.326 | 0.16 |

环的半径、缝隙位置、各区光深都换成能对上公开资料的数值（土星赤道半径 60268 km），
再叠一层确定性的高频环脊纹理。几何从 1.18–2.52R 改成 **1.110–2.330R**（D 环内缘到 F 环）。

**亮度按光深算，不再是常数：**

```glsl
float lit = 1.0 - exp(-tau / max(mu0, 0.035));   // 被照到多少（太阳仰角 μ0）
float opa = 1.0 - exp(-tau / max(mu , 0.035));   // 挡住多少（视线仰角 μ）
```

**两个方向都真的投影：**

- 行星影子投在环上：从环上的点朝太阳打一条射线，和土星球体求交，`disc>0` 且
  交点在太阳一侧就压暗，边界用 `smoothstep` 做半影；
- 环影子投在球面上：在行星着色器里从表面点朝太阳走到环平面，交点半径落进环区
  就按 `exp(-τ/μ)` 衰减直射光。因为 τ 是采样同一条 LUT 的，影子会带出
  B 环的厚、卡西尼缝的细亮条，而不是一条均匀黑带。

### 顺带修掉的一个真 bug

```js
rmat.uniforms.uRingN.value.set(0,0,1)
  .applyMatrix4(new THREE.Matrix3().setFromMatrix4(b.ringMesh.matrix))  // ← 一直是 NaN
```

`Vector3.applyMatrix4` 按 **16 元素** 读矩阵，`Matrix3` 只有 9 个，`e[11]/e[15]`
是 `undefined`，于是法线变成 `NaN`，旧环的 `lit` 从 v1 起就是 NaN（在不同驱动上
退化成黑环或白环）。改成 `applyQuaternion(b.ringMesh.quaternion)`。
修完以后用数值探针验证：受光半球 205 个采样点里 30 个被环遮挡——影子是真的在算，
不是画上去的。

## 2. 月球：接入 LOLA LDEM 真实高程

仓库里本来就有 `public/data/nasa-svs4720-ldem16-uint16le.bin`（5760×2880，
16 px/deg，海拔 = (uint16−20000)×0.5 m），一直没进渲染。这一版把它接上：

**逐像素法线（主要贡献）**
高程栅格上传成 `R16F` 半浮点纹理，片元里取东/北两个方向的差分，把梯度压进法线：

```glsl
float stepU = 2π · 1737400 · max(cos(lat), 0.06) / uDemW;   // 一个 texel 对应的地面长度（米）
n = normalize(n - tE * sU * uDemK - tN * sV * uDemK);
```

差分的是**实测高程**，不是噪声假凹凸。公里级坑缘、月海边缘的暗棱、晨昏线附近的
立体感都来自这里。

**几何位移**
用 DEM 重建月球网格（1280×640 ≈ 82 万顶点，5~7 km 一个顶点），
`r = 1 + h/R`。边缘（limb）不再是完美圆，掠射角的坑缘会真的凸出轮廓。

**数据取舍**
HTTP 模式取 16 ppd 原文件（33 MB）；离线单文件用 8 ppd 降采样
`data/moon-ldem8.bin`（8.3 MB，内联进 `__ORBIT_INLINE__.moonLdem`）。
8 ppd 也仍然是 3.8 km/px，远细于 5~7 km 的顶点间距，所以离线版几乎无损。

**曝光重标定**
LROC 是 Hapke 归一化的「看着像照片」的图，再乘 `uLight(2.35)` 与冲效应
`surge(≈1.85)` 后，满月相位峰值到 1.8 以上，整盘削顶成白饼——月海层次和
DEM 起伏全被压平。图就位后的增益从 1.10 收到 **0.52**，峰值落到 ~0.9。

## 3. 金星 / 海王星：这是数据天花板，不是实现问题

上一版说「只有 2k 源」。这一版查过所有公开渠道后确认：

- **金星**：可见光看到的是硫酸云顶，全球拼图最好的公开版本就是 2k
  （Solar System Scope 只提供 2k atmosphere；8k 只有雷达**地表**，
  那是另一个物理层，不能拿来当云顶）；更高分辨率的都是局部轨道器影像，拼不成全球。
- **海王星**：只有旅行者 2 号 1989 年一次飞掠，全球图 2k 就是上限，
  此后没有任何探测器再去过。

所以「提高分辨率」在这两颗上没有诚实解法，能做的只有把 2k 用对：

1. **取景修好**：行星默认机位改成「日–星连线偏约 40°」（`sunlitDir`）。
   原来直接沿用上一处视向，跳到木星经常正好对着夜面——球是立体的，但整盘黑成一片。
   这不是造假：飞到行星旁边时观察者站哪儿本来就自由。
2. **冰巨星临边收敛**：`rimK` 1.0 → 0.45，原来那圈白边把整颗球糊成发光球。
3. **海王星大气权重** 0.55 → 0.40。
4. 各向异性过滤 8 → 16。

## 仍然不宣称的

1. LDEM 是 16 ppd（≈1.9 km/px）产品，不是逐米测绘；`uDemK=0.62` 是观感系数。
2. 环是零厚度薄盘：τ 剖面来自公开环区数值 + 环脊纹理，**不是** Cassini 逐圈反演；
   没有粒子动力学、没有厚度、没有 G/E 环。
3. 金星/海王星的表面分辨率受限于公开数据，2k 就是上限。
4. 夜面补光（1/3）与 `uDemK` 都属于观感参数，不是物理量。
