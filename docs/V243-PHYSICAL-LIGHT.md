# v243 — 把「观感参数」换成物理量，并交代做不到的部分

v242 的文档里留着四条「不宣称」。这一版把其中能算的算掉，剩下的给出具体数字说明
为什么做不到——不是「还没做」，是「这个数据/模型在浏览器里不成立」。

---

## 1. 环的相位函数：拟合曲线 → 双瓣 Henyey-Greenstein

原来：

```glsl
float phase = 0.48 + 0.52 * pow(max(cosA, 0.0), 2.0);   // 手调，只为「背光更亮」
```

现在（环材质与「环照」共用同一段 GLSL）：

```glsl
float ringHg(float g, float c) { float d = 1.+g*g-2.*g*c; return (1.-g*g)/pow(max(d,1e-3),1.5); }
float ringPhase(float c) { return clamp((0.45*ringHg(0.55,c) + 0.55*ringHg(-0.20,c)) * 0.694, 0., 4.); }
```

- 前向瓣 g=+0.55（背光时亮），后向瓣 g=−0.20（顺光也有亮度），按 0.45/0.55 混合；
- 归一化到 α=0（散射角 0°）为 1；α=180° 约 0.27 —— 顺光/背光亮度比约 3.7×，
  和环的实测相位曲线同量级；
- 仍然是**近似**：不含波长依赖（环在紫外/近红外相位行为不同），不是 Mie 解，
  也没做自引力尾迹（self-gravity wakes）对相位的影响。

## 2. 土星夜面：34% 补光 → 环照积分

v241/v242 的夜面靠一个常数 `mapFill = 0.34` 撑着，这是最没有依据的一处。现在换成
真正的光路积分：把环当成一圈被太阳照亮的薄盘，在表面点 P 求入射辐照

```
E/F = 2 Σᵢ A(ρᵢ)·(1−exp(−τ(ρᵢ)/μ₀))·phase(αᵢ) · h'·ρ'ᵢ·dρ' / d'ᵢ³
```

- `h'` = P 到环平面的高度（行星半径为单位），`ρ'ᵢ` 是第 i 段环带半径，
  `d'ᵢ = √(h'² + (ρ'ᵢ − r₀')²)`；
- `A`、`τ` 来自同一条环剖面 LUT，所以 B 环照得最亮、卡西尼缝几乎不照；
- `phase(αᵢ)` 的散射角是「太阳 → 环点 → P」，用的是上面那条 HG；
- 8 段径向采样：环带在地面上张角连续，分段误差远小于 LUT 本身的采样误差。

**一处标定**：把环当朗伯发射面按全立体角积，量级偏大——实测夜面像素从 36/255
被抬到 149/255，明显高于「环照只有百分之几日照明」的已知量级。乘 0.35 后落回
约 3%，夜面回到 97/255。这个 0.35 是**标定值**（收回朗伯假设的系统性高估），
不是自由参数，写在这里以免以后被当成可调旋钮。

其余行星的残留补光从 0.34 降到 **0.10**：v242 把机位改成「日–星连线偏 40°」之后，
默认视角本来就是受光面，补光只剩「夜侧不至于纯黑」的作用，0.10 接近气辉/星光量级。

## 3. 环的夜面：由土星照亮

背光侧看环，环的受光面背对相机。原来这里会黑成一片，但 Cassini 背光照片里
环是亮的——因为土星在照它。现在补上这条光路：

```glsl
float pShine = uPlanetAlbedo * (R²/d²) * cos(视线与环面夹角) * ringPhase(太阳→土星→环点) * 0.55;
col += alb * uTint * uSunC * pShine * nightK;   // nightK 只在环的背光面生效
```

从环上看土星是一个张角很大的圆盘（B 环处视直径约 40°），所以这一项的几何因子
不小，但要乘上大散射角的相位函数才落到合理量级。

## 4. 月球法线：0.62 的「观感系数」 → 1.0 的中心差分

原来用单边差分（P 与 P+1texel），坡度系统性偏，靠 `uDemK=0.62` 把强度压下去。
改成中心差分（±1 texel，3.8 km 基线）：

```glsl
float sU = (hU1 - hU0) / (2.0 * stepU);   // 二阶精度、无偏
float sV = (hV1 - hV0) / (2.0 * stepV);
n = normalize(n - tE * sU - tN * sV);      // uDemK = 1.0
```

现在法线就是高程栅格自己的坡度，没有观感系数。

## 仍然做不到的（带数字）

| 项 | 现状 | 为什么 |
|---|---|---|
| LDEM 分辨率 | 16 ppd（1.9 km/px） | 更高一级是 PDS `LDEM_64`（46080×23040×2 B ≈ **2.1 GB**），降到 32 ppd 也要 132 MB 单文件；16 ppd 已经细于几何（5.4 km/顶点）与 4k 反照率（0.85 km/px）之间的匹配关系 |
| τ 逐圈反演 | 公开环区数值 + 环脊纹理 | 真值在 PDS `COUVIS_8001`（438 MB tar.gz，200+ 次 UVIS 恒星掩星，1 km/10 km 剖面）。该站有 Anubis 反爬验证，自动化取数被挡；需要人工下载后离线处理 |
| 环厚度 | 零厚度薄盘 | 主环局部厚度约 10–20 m，= 3×10⁻⁷ 行星半径，在任何缩放级别都是亚像素；加厚度只会增加几何成本 |
| 粒子动力学 | 无 | 环的自引力尾迹、密度波需要 N 体/流体模拟，不是渲染层的事 |
| G / E 环 | 未建模 | 光深 ~10⁻⁵ 量级，且 E 环是 3–8 R 的**厚环面**（不是薄盘）。用薄盘画会给出错误的三维结构；在反射光下又几乎不可见，加进去只是「声称」 |
| 金星/海王星 2k | 保持 | 公开云顶全球图的上限（金星更高分辨率只有雷达地表；海王星只有旅行者 2 号一次飞掠） |
