# P2 两场景坐标和对象标定（独立实验）

运行：`node tools/p2-axis-calibration-independent-20261117.cjs`。最终报告 `.workbuddy/p2-axis-calibration-74dd0e78-0ecd-4019-b00a-8e3d1385d0fc/report.json`；Chrome Headless 157 / RTX 4060，八项探针检查通过，状态 `measured-not-validation`。源码、正式入口和 PROGRESS 均未写入；构建输出中的文件名是原构建日志，真正输出在独立目录。实验前后所列输入哈希不变。

## 方向坐标约定

主方向 `v=(x,y,z)` 映射至宇宙方向 `M v`，矩阵按列为：

```
[-0.0548739562, -0.4838350314, -0.8734371822]
[-0.8676661490,  0.4559837762, -0.1980763734]
[ 0.4941094730,  0.7469826421, -0.4448289122]
```

这是由运行时 `GA` 和 `galWorld` 派生，非拟合出的精确正交矩阵：行列式 0.999999999999，最大轴单位长度/内积偏差 1.0616e-6。银心赤经赤纬方向在宇宙系约为 `(1, -1.381e-6, 0)`，但 `SUN_GAL=(2.5148272289e20,0,0)`、银心几何原点为 0；这与太阳到银心通常应指向 -X 的位置几何不一致，属于目前实现约定的矛盾，不能通过简单加太阳偏移假定所有对象同物理坐标。

## 星点与共同星系

从两侧实际构建的 BSC 缓冲区按原始目录索引对应抽取 7 颗星，主侧按亮度桶定位，宇宙侧读取 localStars 的 Float32 顶点并减太阳锚点。方向变换夹角误差 0.000128–0.000472°；错误的轴同向比较误差 44.90–116.89°，错误翻转 Z 比较 15.03–142.02°。这证明受测缓冲数据的方向约定，而非运动中光点的屏幕位置：主侧是相机中心固定半径天球，宇宙侧估算距离且带 shader 坐标、相机偏移和尺度相关开关。

对主侧实际 sprite 方向及宇宙侧 `CS.gals[i].userData.pos`，四个共同对象的旋转后方向误差分别为：M31 0.003889°、M33 0.001720°、大麦哲伦云 0.016366°、小麦哲伦云 0.040457°；主侧 RA 为小时、宇宙目录为角度，精度不同。直接相同轴则分别为 119.16°、121.22°、76.37°、42.38°。宇宙对象实际 `pos` 从银河原点定义，减去太阳坐标后的方向相对主侧旋转方向误差分别为 0.5263°、0.4499°、9.3804°、7.3974°；仅比较从原点出的 galWorld 方向会漏掉这一区别。

人为宇宙机位 R=2e20、target=0 并执行实际 `cosmicUpdate(0)` 后，四个真实 `galPts` 属性顶点与对应 mesh 中心差 3.8e-7–2.18e-5 渲染单位；这是 float32 顶点与 double 位置对照，不是像素定位。各星系点层开关为真；主侧四个 sprite 的自身 `visible` 为 false，而宇宙 mesh 的自身 `visible` 为 true，均不能替代对完整父链、材质、遮挡和最终像素的验证。

针对每个目标单独以主方向居中、50° FOV、1.5 aspect 构造测试相机，并将前向和 up 同时乘 M；比较目录方向的 Three.js 投影中心，NDC 平面偏差依次为 0.000101、0.0000429、0.000441、0.001038；轴同向错误相机对应 2.570、2.531、8.634、1.363。错误方向可能位于相机后方，NDC 数字仅用于负对照，不是屏幕可见位置或像素误差。该投影使用方向而非实际相机到对象的有限距离向量，不能证明真实场景对齐。

## 限制

测试是源码独立预览，主层 seek 到 lg=19.98，强制预建并人为更新非活动宇宙层，未测自然跨层同一物理时刻、真实 GPU 投影像素、完整投影裁剪和后处理。最初的 `.workbuddy/p2-axis-calibration-12b1f735-d6a1-4032-b9b5-837c616e3b56/report.json` 使用未更新宇宙对象且部分方向位于测试视锥外，只可作历史证据；上述最终报告增加真实更新和按目标居中投影。两侧数据坐标、不同目录太阳偏置和随尺度切换的渲染状态必须分别解决后才能构造可验证物理机位；本实验未修复视觉硬切，也未证明转场完成。
