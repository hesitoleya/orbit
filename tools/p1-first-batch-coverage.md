## 核实方法与边界

1. 对照计划 §四逐名检查对象及其主场景配置、专属 DEEP ID、对象图像映射；目录出现仅记“条目”，不能据此判定可点击或渲染成功。
2. 查看源元数据、生成脚本及原始数据，逐条核对对象、许可、署名、尺寸、波段、处理与哈希；不能从文件名推导来源或授权。E 的链接与哈希只是现有元数据记录，本次未联网或重算。
3. 后续分别在实际离线入口和 HTTP 入口记录版本、设备、目标、设置，逐对象执行正/侧/背/近及进入/返回，留截图和连续录像；确认目标标识及同一相机条件，再填写质量档。当前未执行浏览器、构建、性能测试或视觉验收。
4. 本表只覆盖计划明确命名对象和未指定代表的缺口；未指定类别需先确定具体成员，不能将其算作已完成对象覆盖。
