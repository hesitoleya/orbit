# 隔离坐标候选与浏览器核验

**暂不可安全合并。** 候选对受测坐标与导航的数值检查通过，但尚未完成真实屏幕像素、自然跨场景相机连续性、所有目录语义和动画链路验证。仅在 `tools` 内保存候选生成脚本和独立预览，正式源码及正式入口未改。

## 推导和实现

银心原点、太阳世界坐标 `(+8.15,0,0) kpc`。赤道单位向量在 `GA.gc`、`GA.ngp`、`GA.yg=ngp×gc` 上的投影分别为 `gx,gz,gy`；与 Harris 星团日心坐标 X 指向银心、Y 沿银道经度增长、Z 朝北，且其现有世界坐标 `(8.15-X,Z,Y)` 相匹配，方向应为 `(-gx,gz,-gy)`。注意原始 `GA.yg` 的符号与 Harris Y 相反；不能仅凭叉乘名字猜正负。此变换相对原实现只翻世界 X，是镜像（行列式符号改变），不是可直接用四元数表达的纯旋转。

`galWorld` 保留**日心方向向量**语义；`galPosition` 仅对日心距离加太阳平移，调用方明确使用同单位：米 `8.15*C_KPC`，Mpc `0.00815`。近星原已在 kpc 下加太阳，不再重复加；球团原有直角坐标不变。候选覆盖星系和宇宙目录、M31 取景、两类二进制解码、宇宙网节点和目录导航。原网节点锚点以 Mpc 存储，目录选择时转米；宇宙目录显示距离相对太阳而非银心计算。真实银心方向测量 `(-1,-0.000001381,0)`；微小非正交来自现有天极/银心常数。

## 浏览器测量

- M31、M33、大/小麦哲伦云，位置减太阳后与自身目录方向夹角均约 `10⁻¹⁵°`；距离比例误差小于 `4.3×10⁻⁷`，`CS.flyTo` 目标与 mesh 位置一致。该项是同目录一致性而非独立天文精度证明。
- 七颗 BSC 近星从 Float32 顶点减去太阳再与原始 RA/Dec 比较，误差均低于 `0.002°`。距离是视星等反推的近似值。
- 144 个球团均参与与赤道坐标/距离的交叉检查；最大夹角 `1.1114°`（NGC 6397），最大顶点误差 `3.50×10⁻⁶ kpc`。球团目录 XYZ 以 0.1 kpc 级取整，误差阈值为 `1.2°`。发现文件中球团 RA 实际为**小时**，虽生成器注释标为度；本测试乘 15，未修改目录。首次误按度得到大角度失败；首次误把世界 Z 翻转时最大误差 157.7°，两次失败证据保留于同目录历史报告。
- 人马座 A* 用目录的 0.026 Mly 得到离银心 `0.1787 kpc`，并非零；该值反映目录距离近似与假设太阳银心距不完全一致，不应硬断言黑洞处于精确原点。
- 人造单条星系点和纤维二进制分别走真实解码路径；相对预期误差 `6.84×10⁻⁶`、`6.05×10⁻⁶ Mpc`（Float32）。室女座节点锚点一致。
- 目录选择 Sgr A*、宇宙网节点、球团 `focusCluster`、球团标签及 M31 标签的受测目标数值误差均为零。这里为隔离候选注入同步过场回调，执行真实选择/点击处理，但**未测试真实过场动画、UI 可见性或物理点击命中**。

## 风险与后续

1. 主场景与宇宙场景的相机、up、天空、银河贴图取向及进出方向必须以镜像变换重新检查；已有旋转矩阵及任何四元数插值不再适用。当前没有自然跨层逐帧实测、同帧视觉对照及屏幕像素/遮挡验收。
2. 不同目录距离可能使用日心、共动或示意约定；候选按日心解释当前 RA/Dec 距离，需逐目录查证，包括大尺度近似、Sgr A* 数据和 CMB。程序化宇宙网、纹理姿态、照片方向也未复核。
3. 二进制解码只测人工记录，未验证实际整表、远端加载、默认关闭的纤维层以及跨浏览器；导航测试绕过动画与用户交互序列。
4. 世界节点标签点击原本不飞行，候选仅修目录选择单位；是否改变标签行为需单独确认。正式代码中的旧注释还应在合并时同步纠正，球团生成器的 RA 小时/度文档错误须单独修复。
5. 预览经内存补丁，仅供验证；要合并应先以明确类型/单位修改正式源，增加独立标准坐标与端到端回归，再验证构建、性能和视觉。不可把此次 `passed-limited` 当成生产验收。
