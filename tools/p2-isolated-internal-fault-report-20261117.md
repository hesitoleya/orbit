# P2 双页面内部异常实验

运行：`node tools/p2-isolated-internal-fault-20261117.cjs`。本实验复用现有 `p2-isolated-pages-20261117.cjs`，在内存中改写实验代码和构建模板；输出仅在 `tools/p2-internal-fault-report-*` 下，不改产品或 PROGRESS。构建日志里的正式文件名仅为原日志，实际输出是实验目录里的 preview。

## 结果

报告 `tools/p2-internal-fault-report-5d9906c4-3d87-436a-853d-50d1a477e7a1/report.json`，状态 `prototype-observed-incomplete`，驱动及输入哈希检查未报告错误。正常及异常各使用新建页面：主页面先采样，宇宙页面预建并调用真实 `cosmicUpdate(0)`。异常组在相机逆矩阵更新后、pxPerRad 计算之前注入 JS 异常，确认收到指定异常后销毁该页；主页面继续采样，然后新建宇宙页面重新构建、更新、采样并关闭，主页面再次采样。检查到相应页面可绘制非零像素、帧缓冲完整且未报告 GL 错误；正常组宇宙采样亦通过现有探针检查。

每组显示 8 项布尔值，但其中按案例条件不适用的项固定为真，不能称为每组均独立完成 8 项测试；只在异常组执行重建及之后主页面采样。首次运行 `tools/p2-internal-fault-report-c17f74c9-7ef3-4e4c-b7af-8807f813fd65/report.json` 因 VM 未配置动态导入回调而在构建前失败；改为 Node 模块编译后复测，失败证据保留。

## 边界与下一步

- 这是抛弃故障实例后重建，不是事务回滚；主页面可采样只证明本次列明观察，不证明全部状态、资源、画面未变化。独立页面共享浏览器、GPU、缓存，不能证明进程或硬件故障隔离。
- 双页面并非同一 GPU 帧，也未冻结时钟、随机序列与异步资源；宇宙相机人为构造，物理机位、投影及资源就绪未验证。固定种子并不等于资源或时间已确定。
- 采样绕过生产后处理，半浮点量化有截断风险；未验证端点、视觉、转场、性能，也未测试真实 context loss、资源分配失败或异步异常。内存预览不是产品修复。
- 下一步先定义可重放输入快照、时间与资源就绪屏障，隔离可写对象、动态数组、材质、DOM 及生命周期；在单渲染器实例上分阶段注入失败并审计副作用，而非依赖部分字段恢复。再验证物理坐标/投影映射、HDR 和生产后处理端点及真实故障。
